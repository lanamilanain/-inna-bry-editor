Редакционные правила

  • Естественный разговорный язык, без канцелярита.
  • Одна ясная мысль на один слайд.
  • Не менять исходные фотографии.
  • Не добавлять декоративные элементы без необходимости.
  • Для ленты использовать вертикальный формат 3:4.
ТВОИ ДАННЫЕ ПОД ТВОИМ КОНТРОЛЕМ

Данные и копии

Все записи хранятся локально в браузере на этом устройстве. Серверная передача не используется.

Экспорт данных

Скачай резервную копию публикаций, идей, аналитики и продуктов в JSON.

Восстановить данные

Загрузи ранее сохранённый JSON-файл. Импорт объединит данные по типам, не удаляя текущие записи.

Что важно знать

  • Данные доступны в этом браузере на этом устройстве.
  • Очистка данных Safari может удалить локальные записи, поэтому регулярно скачивай копию.
  • Для переноса на другое устройство экспортируй JSON и импортируй его там.
  • Фотографии и проекты конструктора каруселей хранятся отдельно внутри самого редактора.
  • Платные API и обязательные подписки не используются.
